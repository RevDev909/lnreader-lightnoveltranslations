# Light Novel Translations — test build

Test build of the official Light Novel Translations plugin with the fix for
lnreader/lnreader-plugins#2718 ("No results found" after the site's browse
redesign), version 1.0.1.

Install in LNReader by adding this repository URL:

```
https://raw.githubusercontent.com/RevDev909/lnreader-lightnoveltranslations/main/.dist/plugins.min.json
```

This is a temporary test repo. Once the fix is merged upstream, install the
plugin from the built-in sources instead and this repo can be deleted.
